# Kestrel Credit Appraisal Copilot: Screen & Route Map

This screen map details the translation of Google Stitch design outputs into production-grade React components, routes, and role-based access boundaries.

---

| `institutional_authentication_role_selector` / `kestrel_credit_appraisal_copilot` | Kestrel Credit Appraisal Copilot: Institutional Authentication & Role Selector | `/sign-in` | Public / All | Dual-tab sign-in (User vs Owner), institutional credentials, simulated 6-digit MFA token with countdown, quick-fill demo personas, governance disclaimer banner, session timeout notice. |
